# Ferment

Small bit of transformed matter added to base mass to convert whole, like leaven in dough.

This repository contains the starter chart helmetica's transmuter creates every reagent from.
Transmuting copies this README into the new reagent: replace it there with a short description of the service and a link to its docs.

Documentation: https://docs.helmetica.io/ferment/

## Development

```console
$ just test        # lint and unit tests, no cluster needed
$ just touchstone  # end to end against a running athanor
$ just docs        # preview the docs
```
